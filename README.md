# Satria Arifin — Personal Profile

Website profil pribadi dengan tema **merah maroon elegan**, dibuat menggunakan HTML dan CSS sehingga cocok untuk GitHub Pages.

## Struktur
- `index.html` — halaman utama
- `style.css` — desain, gradient, responsive layout

## Cara upload ke GitHub
1. Buat repository baru di GitHub, misalnya `satria-profile`.
2. Upload `index.html` dan `style.css`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`.
6. Simpan. Setelah proses selesai, GitHub akan memberikan alamat website.

## Menambahkan foto galeri
Buat folder `images`, masukkan foto jogging, lalu ganti bagian `gallery-placeholder` pada `index.html` dengan tag gambar `<img src="images/nama-foto.jpg" ...>`.
